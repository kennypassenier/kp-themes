Layout layer

Classes for the shape of a page, in the cascade layer after the components, so a layout class wins on a component that sets the same property itself. Every value reads a knob whose default is the theme spacing scale.

The 26 rules

SelectorWhat it is forKnobs
.kp-pageThe page itself: a measure to read within, centred, with margins that shrink on a phone instead of stepping at a breakpoint. Knobs: --kp-page-max (64rem), --kp-page-pad (between the md and xl steps of the scale, 3vw in between), --kp-page-pad-block (the xl step).--kp-page-max, --kp-page-pad, --kp-space-md, --kp-space-xl, --kp-page-pad-block
.kp-stackVertical rhythm. This is the fault the round started from: two fields and a button touched because a field has no vertical margin and nothing above it supplied one. Knob: --kp-stack-gap (the md step).--kp-stack-gap, --kp-space-md
.kp-rowA row of controls that wraps rather than overflowing, aligned on the centre by default because that is what a row of controls wants. Four modifiers change one thing each. Knobs: --kp-row-gap (the sm step), --kp-row-align (center).--kp-row-gap, --kp-space-sm, --kp-row-align
.kp-row--endAligns the row on the bottom edge, which is what a field beside a button wants.—
.kp-row--startAligns the row on the top edge.—
.kp-row--betweenPushes the ends of the row apart.—
.kp-row--nowrapRefuses to wrap.—
.kp-autogridA grid that adds a column when there is room for one, with no breakpoint anywhere. The minimum track is the knob: a card wants 16rem, a tile less. It keeps a little air on all four sides so the first column's text never sits against the edge of whatever it lands in (Kenny, 2026-09-08). Knobs: --kp-autogrid-min (16rem), --kp-autogrid-gap (the lg step), --kp-autogrid-pad (the sm step; set it to 0 for a grid that should reach its container's edge).--kp-autogrid-min, --kp-autogrid-gap, --kp-space-lg, --kp-autogrid-pad, --kp-space-sm
.kp-autogrid--tightA tighter minimum, for a grid that must keep its columns on a phone (three footer columns at 320px; the concept demo, round six).—
.kp-page--fullA page that uses the whole viewport: two frames side by side need the width more than the measure (the compare page, round six).—
.kp-sidebarContent with a side column that drops below when there is no room for both — no media query, so it behaves the same inside a narrow container as it does in a narrow window. The aside drops once the main column would be narrower than half the track. Knob: --kp-sidebar-gap (the lg step).--kp-sidebar-gap, --kp-space-lg
.kp-sidebar > .kp-sidebar__asideThe side column. Knob: --kp-sidebar-width (16rem).--kp-sidebar-width
.kp-sidebar > .kp-sidebar__mainThe main column, which takes every spare pixel. Knob: --kp-sidebar-break (50%), the narrowest it may be before the aside drops below it.--kp-sidebar-break
.kp-shellAn application shell: the bar on top and a body under it that fills the rest of the window, so a rail beside the content runs to the bottom of the window rather than stopping where the content does (scope-80). The body is a row that wraps, the rail and the content its items. Knob: --kp-shell-min (100dvh), the least height of the whole shell.--kp-shell-min
.kp-shell > .kp-shell__bodyThe shell's body, which takes every spare pixel of that height.—
.kp-sectionA section of a page: space above it, and nothing else. The heading inside keeps whatever the theme gives it. Knob: --kp-section-gap (the 2xl step).--kp-section-gap, --kp-space-2xl
.kp-section:first-childAs the first child a section puts no space above itself, where the space would push the page down for no reason.—
.kp-centerA box with a ceiling, centred — the login card, the empty state, the one-column form. Knob: --kp-center-max (28rem).--kp-center-max
.kp-proseRunning text stops at a readable measure. ch rather than rem, because the measure is about characters per line and the themes ship faces of very different widths. Knob: --kp-prose-max (65ch).--kp-prose-max
.kp-text-mutedExactly the theme's --muted-foreground, never a lightened copy of the body colour.—
.kp-text-endAligns text to the end. This and .kp-text-center are the reason the layer exists at all: a table cell sets its own alignment at higher specificity, so before the cascade layers these two did nothing inside a table.—
.kp-text-centerCentres text; see .kp-text-end for why it is in this layer.—
.kp-monoThe package's own monospace face. Knobs: --kp-mono-face (the theme's --font-mono), --kp-mono-size (0.9em).--kp-mono-face, --kp-mono-size
.kp-code-blockA block of code that breaks rather than widening the page. A key or a token has no spaces to break at, which is why anywhere and not break-word. It sits on a card and reads --kp-mono-face like .kp-mono.--kp-space-md, --kp-space-lg, --kp-mono-face
[data-kp-sticky]Opt-in, by an attribute rather than a class, because staying put is a behaviour of that element on that page and not a kind of element. Knobs: --kp-sticky-top (0), --kp-sticky-layer (30). It has a partner on the html element: --kp-scroll-offset (0px) is how far an in-page link stops short of the top, and a page that sticks its nav sets it to the height it stuck. Without it the skip link every page carries lands underneath the bar, and the person using that link is exactly the person who cannot see that it did. --kp-scroll-behavior (auto) turns on smooth scrolling, read inside the reduced-motion guard so smooth cannot survive a reader who asked for less motion. All three defaults change nothing: a page that does not ask gets what it got before.--kp-sticky-top, --kp-sticky-layer
[aria-busy='true']Standing rule 31 says a button that starts something slow shows it. The behaviour was already in the package and the styling was not, so the chassis kit wrote this rule itself. It belongs here. The busy state made visible: the element dims and the cursor becomes a progress cursor. An attribute rather than a class, because the attribute is what a screen reader already reads, and a busy control that looks identical to an idle one is the fault correction KT6 exists about. Knob: --kp-busy-opacity (0.7).--kp-busy-opacity
