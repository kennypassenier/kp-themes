Utility API

118 single-purpose classes in the last cascade layer, so a utility beats a component value without an override. There are no breakpoint variants; the layout containers do responsive work instead.

Text

No `.kp-truncate`: css/components.css already declares it, with a display and a max-width this family would drop. The collision gate found that. The font-size family reads the three steps the components actually use; there are three rather than six because the scale has three, and inventing steps nothing uses would be inventing values. Alignment, the muted colour, the mono face and the prose measure are layout classes (TH91), not utilities.
