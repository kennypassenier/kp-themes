Console

A prompt and, per command, a block that shows whether it still runs, worked or failed: the command, its exit code, its output folded and copyable, and a refusal in what and what to do now. The app runs the commands; the package draws the shell of the interaction and remembers your earlier lines for as long as the tab is open.

When to use it

An admin page that runs a command on a host or a container and shows what came back. For a stream of log lines use the log; for one captured request use the request inspector.

Accessibility

  • Built in — the output is a log region, a running block is busy, only the last command’s result is announced (never its output), a refusal is an alert, the prompt says why it is off.
  • Yours — everything about what a command may do, and masking secrets in the output.
