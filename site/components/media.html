Media

A frame for a picture or a video that has its final shape before the picture arrives, so the text below it does not jump when the bytes land.

When to use it

Wherever a page shows an image whose size it does not control — a hero, a card’s thumbnail, an avatar. Not for a decorative background, which is a background. Not for an icon, which has one size and needs no frame.

Framework-free markup

Server-rendered markup with the behaviour attached by js/auto.js, the one module that does anything on import. The snippets above are that markup, printed from the same string the example renders.

These are the framework-free channel's props. A selector is how a module finds an element, a read is a value you set on it, and a written one is state the module puts back for the stylesheet and for you to read.

Accessibility

  • Yours — every image needs alt text, and a decorative one needs an empty alt rather than none.
  • Yours — a caption that repeats the alt text is read twice. Say different things, or leave one out.
  • Built in — the frame keeps its shape before and after loading, so nothing the reader is looking at moves under them.

Variants and states

NameWhat it is
.kp-media--wide21/9, for a hero that spans the page.
.kp-media--square1/1, for a grid of thumbnails.
.kp-media--portrait3/4, for a person.
--kp-media-ratioAny other shape. Default 16/9.
--kp-media-fitcover by default — the picture fills the frame and is cropped. `contain` fits it whole, with the frame’s ground showing around it.
--kp-media-positionWhich part survives the crop. Default the middle; `50% 20%` keeps heads in the frame.
.kp-media__overlayText on the picture, with a gradient under it. Its ink and its ground are knobs for a consumer who knows their own picture.
