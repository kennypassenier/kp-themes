Form rows

A settings form as rows: the label, the package’s own control with its help or error under it, and an aside for where the value comes from or an Edit button. The label column is as wide as the longest label; under 36rem each row reads top to bottom.

When to use it

A settings page or a long form of independent values.

Live example

Framework-free markup

Server-rendered markup with the behaviour attached by js/auto.js, the one module that does anything on import. The snippets above are that markup, printed from the same string the example renders.

These are the framework-free channel's props. A selector is how a module finds an element, a read is a value you set on it, and a written one is state the module puts back for the stylesheet and for you to read.

This unit reads no data attributes of its own.

Accessibility

  • Built in — the label is a real label.
  • Yours — tie help and errors to the control with aria-describedby.

Variants and states

NameWhat it is
.kp-formrows--linesA hairline between rows.
.kp-formrow--top / --wideThe label at the top for a tall control; the control takes the aside’s column too.
data-kp-changed / data-kp-state="error" / data-kp-lockedOn a `.kp-formrow`: a rule on the start edge for a value not saved; a destructive rule for a failed one; the label muted for a value the reader cannot change, with `.kp-formrow__lock` in the aside saying why.
.kp-formrow__label smallThe setting’s own key under its label, in the quiet face.
