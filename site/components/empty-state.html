Empty state

A bordered box that says a list is empty, and which emptiness it is: nothing yet, or nothing that matched. A blank area says the page is broken instead.

When to use it

Wherever a list, a table or a search can come back with nothing. Not as an error message — a failed request is an alert, because the reader can do something about it. Not for a section that is empty by design, where a sentence in the ordinary prose is enough.

Framework-free markup

Server-rendered markup with the behaviour attached by js/auto.js, the one module that does anything on import. The snippets above are that markup, printed from the same string the example renders.

These are the framework-free channel's props. A selector is how a module finds an element, a read is a value you set on it, and a written one is state the module puts back for the stylesheet and for you to read.

Accessibility

  • Built in — the title is text in the page’s own ink rather than a picture of a shrug, so it is read out like any other message.
  • Yours — put the empty state where the list was, so a reader who moved focus into the list is not left with nothing.
  • Yours — announce the change if the list emptied because of something the reader typed; the box appearing is silent on its own.
  • Yours — offer one action, and only the one that fits the emptiness in front of you.

Variants and states

NameWhat it is
attachArt / drawArt`attachArt(root)` draws the picture in every `[data-kp-art]` and returns a detach that takes the drawings out again; `drawArt` makes one. `ART` is the selector, `ART_KINDS` the six kinds and `ART_SETS` the sets: one `<g data-kp-art-set>` each, of which the theme’s register shows its own.
.kp-art__rule / __line / __ink / __redThe strokes of a drawing: a faint ruled line, an outline, the page’s ink and the destructive ink. Each theme draws its own set with them; a theme that has none shows no drawing.
.kp-emptyThe box on its own: a dashed boundary and quiet ink, for a one-line emptiness with nothing to offer.
.kp-empty__titleThe line that names the emptiness, in the page’s full ink so it is not mistaken for help text.
.kp-empty__bodyOne sentence under it, saying what would put something here.
filteredThe same box in its other state, with the action that clears the filter instead of the one that creates a first item.
as a headingThe title can be rendered as a real heading where the empty state stands for a whole section.
data-kp-artA drawing at the top (`.kp-art`, js/art.js `attachArt`): `none`, `nomatch`, `error`, `offline`, `done` or `locked`, in the theme’s own set (`data-kp-art-set`; formal’s is the ledger), ruled in on arrival where the theme moves. `data-kp-art-kind` on the drawing says which.
data-kp-art-size`sm` (5rem) or `lg` (10rem) instead of 7.5rem.

Options written as attributes are read again when they change. A component of your own that reads options from attributes does the same with watchOptions(element, attributes, onChange) from js/live-options.js.
