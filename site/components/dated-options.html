Dated option picker

A choice where every option has a date and an age: radio rows with the name (or the date), how long ago, a “Latest” badge on the newest and a size or kind in one column at the end; a searchable list of the same two lines for a long list.

When to use it

Picking a snapshot, a backup or a version. For options without a moment use the radio group; for one date use the date picker.

Accessibility

  • Built in — the rows are one radio group with arrow keys and type-ahead; the long list is the package’s combobox; the choice is announced; a disabled option says why in its own text.
  • Yours — name the picker after what it restores (`aria-label`), and format the meta (`formatBytes`).

Variants and states

NameWhat it is
data-kp-preselect`false` leaves the newest unchosen; else it is chosen when the options arrive.
data-kp-name / data-kp-valueThe radios’ name, for a form (the element’s id by default), and the value chosen when the options arrive (the newest).
datedAge / orderDatedThe age in words of a moment for a clock, and the options in an order (`newest`, `oldest`, `given`).
datedOptions / setDatedState`datedOptions(el)` gives the options in the order shown; `setDatedState(el, state, { reason, action, title, text })` the other states. `kp-dated-retry` is Try again on a failed picker.
