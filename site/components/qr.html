QR code

A link shown as a QR code a phone can scan, with the link as text under it and a Copy button. The code is drawn on the page; the link never goes to a service. The plate stays light in every theme, because dark modules on a light ground are read by every camera.

When to use it

An invitation, a pairing link or a Wi-Fi string handed from one screen to another. For a link that only needs copying use the copyable value.

Framework-free markup

Server-rendered markup with the behaviour attached by js/auto.js, the one module that does anything on import. The snippets above are that markup, printed from the same string the example renders.

These are the framework-free channel's props. A selector is how a module finds an element, a read is a value you set on it, and a written one is state the module puts back for the stylesheet and for you to read.

This unit has no React component; it is CSS and markup only.

Props

No props: this unit is CSS and markup only.

Events

kp-qr-expiredFired once when the link's time ran out.
kp-qr-retryFired by the Retry of a code that could not be made.

Accessibility

  • Built in — the code is an image named by `data-kp-qr-label` and described by the link, focusable so a screen reader can read the link; Shift+C copies; the result of Copy is announced.
  • Yours — a link is never the only way: the caption always shows it as text.
