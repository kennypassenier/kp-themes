Segmented control and filter chips

A group of buttons that choose among a few values, in two looks: a track with a plate under the chosen segment, or the same buttons as separate pills (`.kp-segmented--chips`). With `data-kp-segmented="single"` (the default) it is a radio group with one value on; with `multi` each press turns one value on or off, several may be on, and none on means everything is shown. js/segmented.js writes the roles, the states, the roving tab stop and, in the track look, the position of the plate.

When to use it

For a choice among two to six values that changes what a list or a chart shows, where every value should stay in sight: a status filter, a view, a range. Not for a long list of values (use a select or a combobox), and not for navigation between pages (use tabs or links).

Accessibility

  • Built in — single is a `radiogroup` with `aria-checked`, multi is a group of toggle buttons with `aria-pressed`; one tab stop in, arrow keys within, Home and End jump.
  • Built in — in multi the arrow keys only move the focus; Space and Enter turn the value, so a keyboard user never changes a filter by passing it.
  • Yours — name the group (`aria-label` or `aria-labelledby`), and say in text near the list what is being filtered.

Variants and states

NameWhat it is
data-kp-segmented="tri"The three-way chip group, used with `.kp-segmented--chips`. Each chip carries `data-kp-segmented-tri="include|exclude"`, absent for either way (`TRI_ATTRIBUTE`, `TRI_STATES`), and the parts `.kp-segmented__mark`, `__state` (the word a screen reader hears after the name, “Chicken, required”), `__summary` and `__live`.
getSegmentedTri / setSegmentedTriRead `{ include, exclude }`, or set both lists without an event. `SegmentedItem.state` is the state a chip is given in `setSegmentedItems`.
data-kp-segmented-moreWritten by the script on a scrolling track, never by you: `start`, `end` or both name the sides that have more segments out of sight, so the stylesheet fades only those edges (`MORE_ATTRIBUTE` in js/segmented.js; `OVERFLOW_ATTRIBUTE` is the overflow mark).
snappingA track wider than its room snaps to whole segments (`scroll-snap-type: x proximity`) and keeps a scroll padding of the fade’s width, so a segment is never left half under the fade.
.kp-segmented--chipsThe same buttons as separate pills instead of a track; the chosen chip takes the primary colour.
.kp-segmented__countA number beside the label. While the group is `aria-busy="true"` it shows a placeholder, so nothing moves when the numbers arrive.
disabled`disabled` on an item, or `aria-disabled="true"` on the group, takes it out of the arrow keys and dims it.
overflowWhen the segments are wider than the group, the group scrolls and the chosen segment is kept in view.
.kp-segmented--blockEvery segment the same width, on a full-width control.
data-kp-segmented-collapse="false"In `multi`, turning every other value on is the same as none, so the group goes back to All. This keeps them on.
data-kp-segmented-thumb / -glide / -overflowWritten by the script, never by you: the plate is placed, it glides only after its first placement, and the segments are wider than the group. The plate’s place is two custom properties on the group, which the theme moves in its own time.
setSegmentedValues / getSegmentedValues / resetSegmentedRead the values that are on (empty is All), set them without an event (the address changed), or turn every value off and fire the event if anything was on.
setSegmentedCounts / setSegmentedItemsWrite the numbers beside the values (null empties one, a value not named keeps its number), or replace the items in place: the values still present stay on and the focus stays on its value.
aria-busy="true"On the group: the counts show a placeholder while their numbers load. Pressing is not blocked.
data-kp-segmented="single-or-none"One value or none: a press on the chosen value lets it go, and nothing chosen is a valid answer (a form of medicine that is not known). A `radiogroup` like `single`.
data-kp-segmented-forThe id of a combobox or tag input the chips are tied to: the two hold the same values both ways, always. The field is left out while every choice is a chip.
data-kp-segmented-topA whole number or `all`: the chips are made from the field’s most used options (`data-kp-uses` on an option, how often it is chosen; the list’s order breaks a tie). Left out, the chips the page wrote stay. While the field is shown and has no placeholder of its own it says “Search all 9”. Read again when it changes.
data-kp-segmented-field="always"Keeps the field on the page even when every choice is a chip; `auto` (the default) leaves it out then.
switchable at runtimeSwitchable at runtime: changing `data-kp-segmented` redraws the control.

Options written as attributes are read again when they change. A component of your own that reads options from attributes does the same with watchOptions(element, attributes, onChange) from js/live-options.js.
