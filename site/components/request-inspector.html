Request inspector

A foldable block for each HTTP request a service captured: the method, the path, the status in its tone and in words, and when. Opened, it shows the headers as key and value, the body as code, “showing the first N of M”, and Copy as curl, as JSON or as the body. Secret headers are masked on screen and in a copy.

When to use it

Debugging webhooks, client calls and delivery attempts. For a log that streams use the log; for one payload use the code block.

Accessibility

  • Built in — each request is an accordion item with its status in words, not only in colour; times are dd/mm/yyyy HH:MM with the exact moment in the title.
  • Yours — send the headers and body as the service saw them and list the header names that are secret; the masking is only as good as that list.

Variants and states

NameWhat it is
toCurl / toJson`toCurl(request, { mask, secretHeaders, origin })` and `toJson(request, { mask, secretHeaders })` (js/request-inspector.js) are what the copy buttons use: a request as a curl command or as JSON, the secret headers drawn as ******** unless `mask` is false. A page that sends a request on can call them too.
.kp-inspector__…The parts of a request: `__row` (the fold), `__method`, `__status`, `__path`, `__source`, `__time`, then opened `__body`, `__heading`, `__headers`, `__secret` (a masked value), `__actions`; and around the list `__bar` with `__filter` and `__count`, `__list`, `__older` (“Show N older”) and `__nomatch`.
the barThe filter bar and its segments scroll inside the card when they are wider than it; the page never scrolls sideways.
data-kp-secret-headersHeader names masked on screen and in a copy; authorization, cookie, set-cookie, x-api-key and proxy-authorization by default.
data-kp-secrets-in-copy`masked` (default: a copy carries ******** and a separate “Copy curl with secrets” button carries the real values), `masked-only` or `real`.
data-kp-requests-open`none` (default: every request folded), `failed` (the 4xx and 5xx are open) or `first`.
data-kp-requests-maxHow many show before “Show N older”; 20, newest first.
data-kp-copy-asThe copy buttons, `curl,json,body` by default.
data-kp-requests-test`false` leaves the Send test button out of the empty list.
loading, empty, error`setRequestsState` lays the busy card over at least three rows; an empty list says so with Send test; a failed one has Retry.
