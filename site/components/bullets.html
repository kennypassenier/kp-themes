Bullet rows

Rows of a value against a threshold: a lead, the label and a detail, a meter whose tick is the threshold, and the exact figure; worst first. js/bullets.js (`setBullets`, `bulletTone`, `attachBullets`); loading lays the data table’s busy card over waiting rows; a failed list has a Retry (`kp-bullets-retry`).

When to use it

Days since the last contact against a limit, a backup’s age, days to an expiry. For one value use the meter.

Framework-free markup

Server-rendered markup with the behaviour attached by js/auto.js, the one module that does anything on import. The snippets above are that markup, printed from the same string the example renders.

These are the framework-free channel's props. A selector is how a module finds an element, a read is a value you set on it, and a written one is state the module puts back for the stylesheet and for you to read.

Accessibility

  • Built in — each meter reads its figure and the threshold.
  • Yours — say in the card what the threshold is.

Variants and states

NameWhat it is
href / pickA row that is a link, or a button that fires `kp-bullets-pick`; its press area is the whole row.
value: nullNothing to measure: a dash and no bar, the row keeping its height.
tonesA value at or past the threshold takes the warning tone (the figure on the warning plate), at or past `bad` the destructive one, and past `max` the bar’s ▸ says so. `bulletTone(value, threshold, bad)` gives the same answer to a page that needs it elsewhere.
state: loadingThe rows are drawn as waiting rows and the data table’s busy card lies over them; the real rows are drawn once the card has gone.
state: empty / errorThe package’s empty state, `.kp-bullets__note` (`.kp-empty` with `.kp-bullets__note-title`, `.kp-bullets__note-text`), filling the height the rows had. An error also has `.kp-bullets__retry`, a normal-size button.
retry: falseA failed list for a read the page cannot repeat: the words and no Retry.
