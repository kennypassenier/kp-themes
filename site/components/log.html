Log

A stream of lines with the time, the source, the level and the message, in four columns that do not move. The shape homelab writes three times by hand and kp-tui carries as `LogPane`; what the web was missing was the component, not the colours.

When to use it

When a reader scans lines as they arrive — a deploy, a job, a service. Not for a table of records, which sorts and filters and belongs in the data table. Not for one message about one action, which is an alert or a toast.

Framework-free markup

Server-rendered markup with the behaviour attached by js/auto.js, the one module that does anything on import. The snippets above are that markup, printed from the same string the example renders.

These are the framework-free channel's props. A selector is how a module finds an element, a read is a value you set on it, and a written one is state the module puts back for the stylesheet and for you to read.

Accessibility

  • Built in — the level is a word in a column of its own, so colour is never the only carrier [fix-1].
  • Built in — the columns are the list's, so a long message wraps inside its own column instead of pushing the ones before it.
  • Yours — give the list a name and say whether it follows the tail, where a reader can scroll it.
  • Yours — announce a line that demands attention; a stream nobody is watching is silent by design.

Variants and states

NameWhat it is
.kp-logThe list: the grid whose four columns every line shares.
.kp-log__lineOne line; it hands its four parts to the grid and paints nothing itself.
.kp-log__time, .kp-log__source, .kp-log__level, .kp-log__messageThe four parts, in that order — the first three stay put and the fourth takes what is left.
data-kp-severitydebug, info, notice, warning, error or critical: the ink of the level and, for the loud three, of the message.
data-kp-sourceThe name to hash into a chart colour. Its value is the full name, so a shortened label can still carry the right hue.
data-kp-currentThe line the reader is pointed at: the muted ground, and no second colour.
