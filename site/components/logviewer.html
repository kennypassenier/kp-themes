Log viewer

The log as a page reads it: lines that keep arriving, kept in a buffer with a cap, found with a marked count, wrapped or not, with or without a time column, the level in colour, copied or downloaded. Following the tail, the pause button and the "N new lines" pill are the package's own, not drawn again.

When to use it

A host or stack log that grows while it is read. For a handful of static lines use the log; for commands you type and the output they print use the console. There is no virtual list: every kept line is a real row, so the cap is what keeps the page light.

Accessibility

  • Built in: the list is a log region that is not read line by line, the find count and the new-line count are said politely and not on every line, every tool is a labelled control, the level is a word before it is a colour.
  • Yours: where the lines come from, masking secrets in them, and what a line means.

Variants and states

NameWhat it is
