Breadcrumb

The trail from the top of the hierarchy to where the reader is now, with a separator drawn by the stylesheet rather than written into the markup.

When to use it

On a page that sits inside a hierarchy deeper than one level, where “up” is a useful move. Not as a history of where somebody has been — that is the back button — and not on a flat application, where every crumb but the last would say the same thing.

Framework-free markup

Server-rendered markup with the behaviour attached by js/auto.js, the one module that does anything on import. The snippets above are that markup, printed from the same string the example renders.

These are the framework-free channel's props. A selector is how a module finds an element, a read is a value you set on it, and a written one is state the module puts back for the stylesheet and for you to read.

This unit reads no data attributes of its own.

React usage

import { Breadcrumb } from '@kp-soft/themes';

Declared in components/overlays.jsx; the package re-exports every component from its root.

Accessibility

  • Built in — the separator is a stylesheet glyph, so a screen reader does not read a slash between every crumb.
  • Yours — use an ordered list; the order is the information.
  • Yours — name the nav element and mark the last entry as the current page.
  • Yours — shorten long names in the middle of the trail rather than dropping levels out of it.

Variants and states

NameWhat it is
separatorDrawn before every entry but the first, from a glyph the theme can change.
current pageThe last entry is text rather than a link, and says it is the current page.
wrappingA long trail wraps to a second line instead of scrolling sideways.
