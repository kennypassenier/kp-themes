Switch

A checkbox that says on and off instead of ticked: a native checkbox with role="switch", drawn as a track and a thumb, with the state in a word beside it. It submits with a form, reads its state from checked and flips with Space, with no script of its own.

When to use it

For a setting that takes effect as it is flipped — alarms on, a live view on. For a choice that only counts once a form is sent, a checkbox says that better; for more than two states, use a radio group or a select.

Live example

Framework-free markup

Server-rendered markup with the behaviour attached by js/auto.js, the one module that does anything on import. The snippets above are that markup, printed from the same string the example renders.

These are the framework-free channel's props. A selector is how a module finds an element, a read is a value you set on it, and a written one is state the module puts back for the stylesheet and for you to read.

This unit reads no data attributes of its own.

React usage

import { Switch } from '@kp-soft/themes';

Declared in components/switch.jsx; the package re-exports every component from its root.

Accessibility

  • Built in — role="switch" on a real checkbox: a screen reader says “switch, on”, Space flips it and Enter does not.
  • Built in — the state is carried three ways: the thumb’s position, the paint, and the word.
  • Built in — with reduced motion asked for, the thumb jumps instead of sliding.
  • Yours — label every switch with what it turns on, not with “on” or “enable”.
  • Yours — a switch acts at once; if flipping it needs a save button, use a checkbox.

Variants and states

NameWhat it is
.kp-switchThe row: a label, so the track, the word and the text are one target.
.kp-switch__inputThe track, with the thumb drawn on it; checked moves the thumb to the end and fills the track the theme’s way.
.kp-switch__stateThe On or Off word beside the track, from the dictionary; aria-hidden, because the role already announces the state.
disabledThe row fades and refuses the pointer; a disabled switch that is on still reads as on.
aria-invalidThe outline an invalid checkbox takes, in the alarm colour; the message under it says what is wrong.
