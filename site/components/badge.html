Badge

A small pill for a state — a status, a count, a label. It says what it is in text; the colour is the second channel and never the only one.

When to use it

To mark a row or a card with a state the reader scans for. Not as a button: a pill that acts is a button, and painting one as a badge hides that it can be pressed. Not for long text either — a badge that wraps to two lines is a sentence wearing a costume.

Framework-free markup

Server-rendered markup with the behaviour attached by js/auto.js, the one module that does anything on import. The snippets above are that markup, printed from the same string the example renders.

These are the framework-free channel's props. A selector is how a module finds an element, a read is a value you set on it, and a written one is state the module puts back for the stylesheet and for you to read.

Accessibility

  • Built in — a coloured badge with no words is disarmed and reported, because seven pale plates are one plate to somebody who cannot tell them apart.
  • Yours — write the state in the badge. A colour with no word is a colour.
  • Yours — if a badge is a filter, make it a button; if it is a link, make it a link.
  • Yours — say what the badge belongs to when it stands alone in a row: “12 unread”, not “12”.

Variants and states

NameWhat it is
.kp-badgeThe default: the quiet ground and its ink, for counts and neutral labels.
semanticA badge carrying a status colour. It must say what it means in text; one carrying none is refused by the contract enforcer.
with a statusThe status attribute is what a consumer paints from, using the theme’s own status pair for that name.
