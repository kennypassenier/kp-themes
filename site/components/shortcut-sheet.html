Shortcut sheet

The dialog that lists what the keys do — the page every application with shortcuts owes its readers, and the one that is usually a paragraph in a help centre.

When to use it

As soon as the application has keys worth learning. Not as the only place the keys appear: a shortcut is most useful printed next to the command it repeats, which is what the palette’s key hints are for.

Framework-free markup

Server-rendered markup with the behaviour attached by js/auto.js, the one module that does anything on import. The snippets above are that markup, printed from the same string the example renders.

These are the framework-free channel's props. A selector is how a module finds an element, a read is a value you set on it, and a written one is state the module puts back for the stylesheet and for you to read.

Accessibility

  • Built in — the dialog gives the focus trap, Escape and focus return; the sheet adds nothing to them.
  • Yours — mark the keys as keyboard input so they are read as keys.
  • Yours — offer a way to open the sheet that is not itself a shortcut, or it can only be found by people who already know.
  • Yours — keep the list current. A sheet that lies is worse than none.

Variants and states

NameWhat it is
.kp-shortcutsThe dialog, narrower than the palette because a key and a sentence need less room.
.kp-shortcuts__listThe definition list, with room above and below.
.kp-shortcuts__rowOne pair: the keys in a fixed column, the description beside them in quiet ink.
.kp-shortcuts__group-labelA small heading over a group of rows, for a sheet long enough to need sections.
.kp-shortcuts-pendingThe hint the shortcut engine shows after the first key of a chord: the keys pressed so far and what can follow, until the chord completes or times out.
data-kp-shortcuts-hintOn <html>: where that hint stands, `centre` (the default, the middle of what is in view) or `bottom-centre` (the middle of its foot); `configureShortcuts({ hintPlace })` does the same. Switched at runtime; never the top.
data-kp-shortcuts-placeWritten by the engine on the hint itself, `centre` or `bottom-centre`, from the option above; the stylesheet places the hint by it.
data-kp-shortcuts-liveOn the sheet: the engine fills it from the shortcuts registered, grouped, with the reserved group first.
data-kp-shortcuts-scope / -groupOn the sheet: list only the shortcuts of those scope names (comma separated), or only those groups, in that order.
data-kp-shortcuts-reserved-group / -emptyThe name of the group of fixed keys (Anywhere by default); `off` leaves out the line shown when nothing is registered.
pastelIn pastel the sheet opens as pastel’s dialog: its pass on its ::backdrop, the landing onto it; it closes as that opening backwards.
