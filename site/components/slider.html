Slider

One value, or a range with two thumbs, on the native range input drawn by the package, with the number in a small box beside it that you can type in. Marks, a bubble over the thumb, a unit, a size or duration format and a vertical form are options.

When to use it

A number in a range where the exact value matters less than the feel: a temperature, a volume, a price range. For an exact figure only, use a number field.

Framework-free markup

Server-rendered markup with the behaviour attached by js/auto.js, the one module that does anything on import. The snippets above are that markup, printed from the same string the example renders.

These are the framework-free channel's props. A selector is how a module finds an element, a read is a value you set on it, and a written one is state the module puts back for the stylesheet and for you to read.

Accessibility

  • Built in — the native range input: arrows, Shift+arrows, Page Up and Down, Home and End, `aria-valuetext` with the unit; the box is a labelled field; a refused value is described by the line under the slider.
  • Yours — name the slider (`aria-label`) after what it sets, and do the work on `kp-slider-change`, not on every `kp-slider-input`.

Variants and states

NameWhat it is
data-kp-slider`single` (default) or `range`: two thumbs that never cross.
data-kp-slider-value`field` (default), `bubble`, `both` or `none`: how the number is shown.
data-kp-format`number` (default), `percent`, `bytes` or `duration`.
data-kp-ticks`auto` or a list, `0,25,50:Half,100`.
data-kp-commit`change` (default, on release) or `input`.
data-kp-orientation`horizontal` (default) or `vertical`.
data-kp-state`loading` shows the skeleton over track and box.
data-kp-min, data-kp-max, data-kp-stepThe range and the step (0, 100 and 1). A typed value is snapped to the step and refused with a line under the slider when it is not in range.
data-kp-value / data-kp-defaultThe value at first (`20,60` for a range) and the one a double-click on a thumb goes back to.
data-kp-unitText after the number (`°C`, `%`, `min`); it is part of `aria-valuetext`.
data-kp-min-gapOn a range: the least distance between the two thumbs; the step by default.
data-kp-nameThe inputs’ name for a form; a range uses `name-min` and `name-max`.
data-kp-disabledEvery control is off; with `data-kp-disabled-reason` the sentence that says why is written under the slider.
