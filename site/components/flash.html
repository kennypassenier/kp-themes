Flash button

A button that shows its result for a moment: the theme’s spinner while the work runs, then a short word (“Sent”, “Copied”, “Refused”), then its own words again. It never changes width, because every face it can show shares one grid cell, so the row beside it does not re-flow under the pointer.

When to use it

A button whose work takes a moment and has a short answer: send a test, copy, save. For a result that needs reading use the toast; for work that can be undone use the undo toast.

Framework-free markup

Server-rendered markup with the behaviour attached by js/auto.js, the one module that does anything on import. The snippets above are that markup, printed from the same string the example renders.

These are the framework-free channel's props. A selector is how a module finds an element, a read is a value you set on it, and a written one is state the module puts back for the stylesheet and for you to read.

React usage

This unit has no React component; it is CSS and markup only.

Props

No props: this unit is CSS and markup only.

Events

EventWhat it means
kp-flashFired on the button, bubbling, at every change of state: `{ state, ok?, word?, line? }`, state `busy` | `success` | `refused` | `rest`.
kp-flash-reloadFired on the button when `data-kp-reload="region"` wants its region read again: `{ target }`.

Knobs

Custom propertyDefault
--kp-flash-line-min1.5rem

Accessibility

  • Built in — a second press while busy does nothing; the result is announced politely whatever its length; the busy state is `aria-disabled`, so the focus stays.
  • Yours — answer a refusal with `{ error, remedy }`, so the sentence says what is wrong and what to do now.

Variants and states

NameWhat it is
data-kp-flash-buttonMarks the button; the script gives it its faces.
data-kp-busy-labelA word beside the spinner while busy; none by default, so nothing widens.
data-kp-flash-msHow long a success stays; 1500.
data-kp-flash-error-msHow long a refusal’s word stays; 3000.
data-kp-flash-wordThe success word; “Done” by default.
data-kp-flash-wordsEvery word the button may say, comma separated, so the width holds them all.
data-kp-width`keep` (default) or `grow`.
data-kp-refusal`line` (default: the sentence under the button), `button` (the button grows to hold it) or `toast`.
data-kp-flash-lineA selector for the element that holds the line; one is made after the button by default.
data-kp-postA URL: pressing the button POSTs there and shows the answer. With `data-kp-method`, `data-kp-post-body` and `data-kp-reload` (`none`, `page` or `region`, the region named by `data-kp-reload-target`).
