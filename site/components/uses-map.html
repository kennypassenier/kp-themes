Uses map

The second view of the matrix: sources in one column, the things that use them in the other, a line for each use. A card lights its lines and dims the rest on hover or focus and pins on a press. Under 640 px the lines give way to a list of cards with their users as chips.

When to use it

One glance at what depends on what: which CV an application uses, which secret feeds which stack. For a full cross-check of every pair, keep the grid view.

Framework-free markup

Server-rendered markup with the behaviour attached by js/auto.js, the one module that does anything on import. The snippets above are that markup, printed from the same string the example renders.

These are the framework-free channel's props. A selector is how a module finds an element, a read is a value you set on it, and a written one is state the module puts back for the stylesheet and for you to read.

Accessibility

  • Built in — the lines are hidden from assistive technology; every card says the relation in words ("CV Developer NL, used by 3: Deloitte, Takto"); one tab stop with arrow keys, Home and End, Space pins, Enter opens the link, Escape lets go.
  • Yours — give every node a label; give a node nobody can open a `disabledReason`.

Variants and states

NameWhat it is
usesRelation / usesPath / setUsesPin`usesRelation(spec)` gives which nodes each node is joined to, `usesPath(shape, x1, y1, x2, y2)` the line between two points and `setUsesPin(el, key)` pins a node from the page. `rememberedView` reads the view kept by `data-kp-remember`.
kp-uses-pin / kp-uses-retry`kp-uses-pin` carries `{ key, side, pinned, related }` (`USES_PIN_EVENT`); Try again on a failed map fires `kp-uses-retry` (`USES_RETRY_EVENT`).
data-kp-view`grid` (default, unchanged) or `lines`.
data-kp-lines-side`sources-left` (default) or `sources-right`.
data-kp-lines-shape`curve` (default), `elbow` or `straight`.
data-kp-lines-light`both` (default: hover or focus lights, a press pins), `hover`, `pick` or `off`.
data-kp-lines-count`on` (default) shows the exact number of uses on each source, `off`.
data-kp-lines-empty-sources`show` (default: "Not used") or `hide`.
data-kp-lines-collapse-belowThe width in px under which the lines give way to the list (640).
