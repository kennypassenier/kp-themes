Growing text box

A multiline field that is as tall as its text, from its least rows up to a cap, then scrolls inside. An opt-in attribute on the existing field: nothing that already exists changes. It measures on input, paste, a script writing the value, a change of width and a font arriving, and it never animates its height.

When to use it

A message, a note or a pasted mail, where the whole text should be seen and the Save button should stay in reach. For code or JSON, the JSON box uses the same growth.

Framework-free markup

Server-rendered markup with the behaviour attached by js/auto.js, the one module that does anything on import. The snippets above are that markup, printed from the same string the example renders.

These are the framework-free channel's props. A selector is how a module finds an element, a read is a value you set on it, and a written one is state the module puts back for the stylesheet and for you to read.

Accessibility

  • Built in — the field stays a native textarea; the counter is announced politely only at 90 % and 100 % of the limit; a disabled box says why through `data-kp-disabled-reason`.
  • Yours — label the box and give the failed state a sentence that says what to do.

Variants and states

NameWhat it is
data-kp-autosizePresent: on. `off`: off. Existing fields never change by themselves.
data-kp-autosize-maxThe most lines (20 by default) or `none`; beyond it the box scrolls inside.
data-kp-autosize-engine`auto` (default: the browser's own `field-sizing` where it has it), `css` or `js`.
data-kp-autosize-shrink`on` (default) gives the height back when text is deleted; `off` keeps the tallest.
data-kp-resize`vertical` (default) or `none`: the drag handle.
data-kp-counter`off` (default), `chars`, `lines` or `both`: an exact count under the box; with `maxlength` it reads "1,204 of 4,000".
data-kp-submit-key`mod-enter`: Ctrl or Command with Enter sends the form, and the shortcut sheet lists it.
data-kp-rememberA name: an unsent draft is kept on this device and cleared when the form is sent.
data-kp-state`loading` lays the busy card over the box and makes it read-only; `error` keeps the text and writes the sentence in the error line.
