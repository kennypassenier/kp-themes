Selection bar

A bar that is there as soon as rows are ticked: how many (exact), which ones, the page’s actions for them and a way to untick everything. It serves a data table, a list of cards or a board. Together with the row keys, rows are ticked without the mouse: j and k walk a cursor, x ticks, Shift+x ticks a range, Esc unticks all.

When to use it

A list where several rows can be acted on together. For the actions of one row use the row actions.

Accessibility

  • Built in — the count is said once after a burst of ticks; the cursor is a ring on the row, not a fill, so a ticked row and the cursor row read apart; on a phone a long press starts selection mode. Rows hidden by a filter are not walked, and skipped rows are counted in what is said.
  • Yours — mark each box `data-kp-select-row`, give rows a key, and use `setSelectionRules` to turn an action off, with its reason, for a selection it does not fit.

Variants and states

NameWhat it is
row keysThe keys of the rows are `rowSelect(el)` (the handle of an element that has them: `keys()`, `clear()`) and `rowSelectKeys(el)` (the keys of the ticked rows, handle or not); `attachRowSelect(root, options)` gives every `[data-kp-select-keys]` and every data table with a select column the keys and returns a detach. The same options are its second argument (`range`, `arrows`, `allKey`, `scroll`). Enter on a row fires `kp-row-open`; `data-kp-select-keys="false"` turns the keys off for one element.
kp-rows-selectFired on the element after the keys changed the ticks: `{ keys, count, source, skipped }`. Boxes that are disabled are walked over by a range and counted in “2 skipped: cannot be selected”.
.is-cursorThe row the cursor stands on: a ring, not a fill, so a ticked row and the cursor row read apart. It survives a refresh by the row’s key.
data-kp-selectingOn a phone a long press on a row (half a second) starts selection mode: every tap on a row then ticks it, until the last tick goes.
.kp-selection__panel / __count / __names / __moreThe parts the script adds: the panel that holds the rest, the exact count in the width of the next digit, the names (wrapping, never cut with an ellipsis) and the exact “+4 more”.
.kp-selection__offer / __result / __refusalThe offer “Select all 312 that match”, the line after an action that some rows refused (`setSelectionResult`), and the reason written under each refused row (the row carries `data-kp-refused`).
.kp-selection__toggle / __clearThe Actions button that holds the page’s buttons on a narrow bar, and the button that unticks everything (Esc does the same).
setSelection / getSelection`setSelection(bar, items, { matching })` feeds the bar by hand for a list with no boxes (a board, a selection held by the server), after which the bar ignores the boxes; `getSelection(bar)` answers `{ keys, items, count, matching }`.
setSelectionBusy / setSelectionResult / setSelectionRulesWhile an action runs the buttons stop answering and the count gives way to the words; a result names how many were done and how many refused, and why; a rule is a function by the action’s id that answers the reason or nothing.
data-kp-selection-forThe ids of the tables or lists it serves, space separated; the nearest by default.
data-kp-placement`sticky-top` (default), `inline` or `floating-bottom`.
data-kp-selection-names`names` (default) or `count`.
data-kp-selection-maxHow many names show before “+N more”; 6.
setSelectionProgress`setSelectionProgress(bar, { done, total })` between `setSelectionBusy` and the end: the busy words are followed by “3 of 7 done”; the end (`setSelectionBusy(bar, '')` or `setSelectionResult`) takes it away. A screen reader hears every quarter, not every row.
data-kp-select-matchingHow many rows match in all: the bar offers “Select all 312 that match”.
data-kp-select-range`shift` (default) or `off`: Shift-click ticks a range.
data-kp-select-arrowsThe arrow keys walk the cursor too (on by default, `false` turns it off), never inside a grid.
data-kp-select-all-keyCtrl+A ticks every row shown, Ctrl+Shift+A unticks them (on by default, `false` turns it off).
data-kp-cursor-scroll`nearest` (default) or `center`.
data-kp-select-hintAn element in the page where the keys are written as a keys line.

Options written as attributes are read again when they change. A component of your own that reads options from attributes does the same with watchOptions(element, attributes, onChange) from js/live-options.js.
