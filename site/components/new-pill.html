New-lines pill

The “12 new lines · back to the tail” pill on a list that grows while it is read. The list follows its newest row as long as the reader is at that end; once the reader scrolls away, rows that arrive out of sight are counted in the pill, which jumps back with one press.

When to use it

A live log, a feed of messages or any list where new rows arrive at one end. For a static list, nothing is needed.

Framework-free markup

Server-rendered markup with the behaviour attached by js/auto.js, the one module that does anything on import. The snippets above are that markup, printed from the same string the example renders.

These are the framework-free channel's props. A selector is how a module finds an element, a read is a value you set on it, and a written one is state the module puts back for the stylesheet and for you to read.

Events

EventWhat it means
kp-follow-changeFired on the scroller when following starts or stops, or the count changes: `{ following, paused, unseen }`.
kp-newpill-jumpFired on the scroller when the pill is pressed: `{ unseen }`.

Accessibility

  • Built in — a row counts only while it is shown, so a filter takes it out of the count, which is exact; the count is said to a screen reader at most every ten seconds.
  • Yours — let the scroller really scroll (`overflow: auto`) and give it a name.

Variants and states

NameWhat it is
data-kp-follow`tail` (default) or `head` for a newest-first list: where new rows arrive.
data-kp-follow-thresholdPixels from the end that still count as following; 24.
data-kp-pill-placement`bottom` or `top`; the end the rows arrive at by default.
data-kp-pill-unit`line,lines`: the app’s word for a row, singular and plural.
data-kp-since-leftOn by default, `off` turns it off (read at runtime): a divider “New since 14:32” before the first row that came while the tab was away.
data-kp-follow-keyThe key that jumps back and follows again; End, or Home for `head`.
data-kp-follow-spaceSpace pauses and resumes following, for a log.
data-kp-follow-toggleOn a button, naming the list: it pauses and resumes the following and says which it will do.
