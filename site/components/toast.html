Toast

A short message in a stack at the corner of the window that removes itself after a while. Errors go to a second, assertive stack, because those are the ones that must interrupt.

When to use it

For confirming something the reader just did, when the result is elsewhere on the page or not visible at all. Not for anything they have to act on — a toast that disappears is not a place for a decision — and not for errors that block progress, which belong beside the thing that failed.

Framework-free markup

Server-rendered markup with the behaviour attached by js/auto.js, the one module that does anything on import. The snippets above are that markup, printed from the same string the example renders.

These are the framework-free channel's props. A selector is how a module finds an element, a read is a value you set on it, and a written one is state the module puts back for the stylesheet and for you to read.

This unit reads no data attributes of its own.

Accessibility

  • Built in — the polite region announces without interrupting, and errors get the assertive one; that split is the whole reason there are two.
  • Built in — a toast is not focused when it appears, so it does not steal the keyboard from what the reader was doing.
  • Built in — the stack sits above the other layers, so nothing draws over it.
  • Yours — put the region in the document once, at the end, and leave it there. A region added at the same moment as its message is not announced.
  • Yours — leave a toast long enough to read, and give anything actionable a home that does not expire.
  • Yours — repeat the information somewhere permanent if the reader may need it later.

Variants and states

NameWhat it is
.kp-toastsThe stack: fixed at the trailing bottom corner, newest last, above every other layer.
assertive stackA second region for errors, which interrupts rather than waiting for a pause.
.kp-toast--success / --warning / --info / --errorA rule down the leading edge in the status colour. The words say it as well.
.kp-toast__closeA dismiss control pushed to the trailing edge, for a toast that does not go by itself.
with an actionA toast can carry one control — an undo — and then it should stay long enough to be used.
