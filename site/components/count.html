Counting number

A number that counts up to what it already says. The page writes the final figure; the effects module reads it, counts to it and puts the same string back — so a page that never loads the module, and a reader who asked for less movement, both simply see the number.

When to use it

For one or two figures that are the point of a page — a total, a score, a count of things done. Not for a table of numbers, where the movement makes the column unreadable, and not for anything a reader needs at once. The final number is authored in the HTML, so nothing is ever hidden behind the animation.

Live example

Framework-free markup

Server-rendered markup with the behaviour attached by js/auto.js, the one module that does anything on import. The snippets above are that markup, printed from the same string the example renders.

These are the framework-free channel's props. A selector is how a module finds an element, a read is a value you set on it, and a written one is state the module puts back for the stylesheet and for you to read.

Accessibility

  • The final number is written in the HTML, so a page without the module and a reader with reduced motion both see the real figure — the count is decoration over content that is already there.
  • At the reduced-motion setting the number never changes at all: it is not counted quickly, it is not counted.
  • The number is not announced while it counts. A screen reader reads the element once, with the figure the page authored.
  • The nearest `lang` decides which separator groups and which one is the decimal point, so a number never counts through the wrong notation.

Variants and states

NameWhat it is
data-kp-tickMarks a number that ticks to its new value when its text is changed by anyone but the module. The first text is the number shown; after that every change counts from the last number shown to the new one.
data-kp-tick-stateWritten by the module: `running` while it counts (with `aria-busy="true"` on the element, so a live region speaks only the number it lands on), `done` after, and from the first moment it is attached.
kp-tickFires on the element, bubbling, when a tick lands: `{ value }`, the number it landed on (`null` when the text held no number and was written at once).
tickTo(el, text, { from, duration })The same by call. `text` left out means the element’s own text is the target; `from` is the number to start at (the one last shown by default) and `duration` the length in ms. Without a number in either, `text` is written at once.
parseTick(text, locale)The first number in a text in the shape the locale writes numbers, with a `render(value)` that writes another value back in the same shape (the same text around it, the same grouping and decimals); `null` when the text holds no number.
attachTicks(root) and TICK_MS`attachTicks(root)` watches every `[data-kp-tick]` under it, including those added later, and returns a detach that makes every running tick land on its number. `TICK_MS` is the default length, 600 ms.
a jump too long to followMore than 400 steps of the number’s precision is drawn as 400, ending on the real number; a reader who asked for less motion, and a tick length of 0, see the new number at once.
