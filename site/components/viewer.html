Viewer

One thing opened large in a modal dialog: a title, how it is shown, its facts, an exact position, a stage and a foot with the way out. The gallery lightbox and the document preview are both this shell. A loading stage is the theme's busy card over the whole stage; a file that fails or cannot be shown is a plate that fills it.

When to use it

You rarely write it yourself: call `openViewer()` when a picture, a file or a long text should be looked at without leaving the page.

Framework-free markup

Server-rendered markup with the behaviour attached by js/auto.js, the one module that does anything on import. The snippets above are that markup, printed from the same string the example renders.

These are the framework-free channel's props. A selector is how a module finds an element, a read is a value you set on it, and a written one is state the module puts back for the stylesheet and for you to read.

Accessibility

  • Built in — a native modal dialog (focus trapped, Escape closes, focus returns to the opener), the title is its name, the position is announced politely.
  • Yours — pass a real title; the facts line is for the kind, size and date.

Variants and states

NameWhat it is
data-kp-viewerMarks the dialog the shell builds.
data-kp-viewer-size`wide` (about 70 % of the window, 90 % high) or `full`; a phone always gets the whole screen.
data-kp-viewer-actionMarks a foot button: `open`, `download`, `print`, `copy-link`.
