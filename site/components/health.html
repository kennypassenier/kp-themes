Health

A dot and a word for the state of something being watched — a service, a job, a connection. The word is what carries it; the dot is the second channel.

When to use it

In a list of things whose state a reader scans down — a status page, a fleet, a set of integrations. Not for the outcome of a single action, which is an alert or a toast. Not for a numeric measurement, where the number itself says more than three colours can.

Framework-free markup

Server-rendered markup with the behaviour attached by js/auto.js, the one module that does anything on import. The snippets above are that markup, printed from the same string the example renders.

These are the framework-free channel's props. A selector is how a module finds an element, a read is a value you set on it, and a written one is state the module puts back for the stylesheet and for you to read.

This unit reads no data attributes of its own.

React usage

import { Health } from '@kp-soft/themes';

Declared in components/patterns.jsx; the package re-exports every component from its root.

Accessibility

  • Built in — the dot is decorative and carries a boundary, so it is visible on a pale card and never the only carrier.
  • Yours — write the state as a word. Three coloured dots in a column are one dot to somebody who cannot tell them apart.
  • Yours — say what the state belongs to, and when it was last measured.

Variants and states

NameWhat it is
okThe success colour in the dot, with the word beside it.
warnThe warning colour: something is wrong but the thing still works.
downThe destructive colour: it does not work.
no stateWithout a state the dot takes the quiet ground — unknown, which is a fourth thing and not a fourth colour.
