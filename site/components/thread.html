Conversation

A conversation in bubbles: `in` on the start side, `out` on the end side and `system` as a centred line, with day dividers, attachments, grouped headers and a Jump to newest button. Each bubble is an article called “From Acme HR, 13/10/2026 14:02”.

When to use it

The correspondence of a dossier, a ticket or an application. For events with no sender use the timeline.

Framework-free markup

Server-rendered markup with the behaviour attached by js/auto.js, the one module that does anything on import. The snippets above are that markup, printed from the same string the example renders.

These are the framework-free channel's props. A selector is how a module finds an element, a read is a value you set on it, and a written one is state the module puts back for the stylesheet and for you to read.

Events

kp-thread-actionFired on the root when a message's own action is pressed: `{ key, id }`.
kp-thread-foldFired on the root when a message is folded or shown whole: `{ key, expanded }`.

Accessibility

  • Built in — times are dd/mm/yyyy HH:mm in Europe/Brussels with the exact moment in each header; every bubble has a Copy text button; long words and addresses wrap anywhere; a long thread scrolls inside its box.
  • Yours — give each message a stable key, and answer `kp-thread-retry` by sending it again.

Variants and states

NameWhat it is
data-kp-thread-order`oldest` (default, like mail) or `newest`.
data-kp-thread-foldHow a long message is shown: `newest` (default: the newest whole, older ones keep their first lines), `full`, or a number N that folds every message longer than N lines.
data-kp-thread-fold-linesLines an older message keeps; 3.
data-kp-thread-groupMinutes (5): consecutive messages of one side from one sender within it share one header.
data-kp-thread-days`off` leaves the day dividers out.
data-kp-thread-avatar`in` (default), `both` or `none`: the sender’s mark beside the bubble.
data-kp-thread-bubbleHow the sides are told apart: `tinted` (default), `plain` or `filled`.
per message`attachments`, `status` (`sending`, or `failed` with Retry) and `actions` (`{ id, label }` buttons that fire `kp-thread-action`).
states`loading` (one waiting bubble on each side), `empty` (“No messages yet” and Add) and `error` (Retry) fill the box.
