Data table

Sorting, searching, paging and row selection over a table the server already rendered. It works on the rows that are in the document and owns no data; a table marked `data-kp-server` asks your `load` for each page instead.

When to use it

For a table a reader will interrogate — hundreds of rows, a search box, a sort on one column or several, a choice of columns, rows that open, values edited in place, arrow keys between cells. Not for thousands without a server behind it: there is no virtualisation, and export is the app’s, from the rows the table hands over. Not for a handful of rows either, where a search box over six lines is furniture.

Events

EventWhat it means
kp-datatable-viewFired on the wrapper when the visible set changes. A contract value [TH26]. Detail: View, plus `rows` and `pageRows` (the elements).
kp-datatable-selectFired when the selection changes; the detail carries the selected row keys and rows.
kp-datatable-sortFired when the sort changes: `{ column, direction }` or null — the first key; the view carries all of them as `sorts`.
kp-datatable-retryFired when the failed state's retry control is pressed; the app loads again and sets the state.
kp-datatable-columnsFired when the reader shows or hides a column: `{ hidden }`, the column indices.
kp-datatable-expandFired when a row opens or closes: `{ key, row, open, cell, expanded }`; `cell` is the detail cell, for an app that fills it then. In a `data-kp-expand-single` table an opening that closed the row open before fires once, with those keys in `closed`.
kp-datatable-requestFired when a server-backed table needs rows: the DataRequest, plus `respond(answer)` and `fail(error)`.
kp-datatable-editFired, cancelable, when an edited value is about to be saved (EditDetail); `preventDefault()` refuses it.
kp-datatable-groupFired when a group row folds or unfolds [J2]: `{ key, row, open, members, folded }`; `members` are the group's rows, `folded` every folded key.

Accessibility

  • Built in — every sortable header is a real button inside the cell, so sorting is reachable without a pointer.
  • Built in — the sort state, the row count and the current page are announced in words, not only drawn.
  • Built in — numbers and dates are read in the page’s locale, so a sort agrees with what the reader sees.
  • Yours — give every row a stable key if you care which rows are selected after a sort.
  • Yours — name the search box and every row checkbox; “select row” is not a name when there are forty of them.
  • Yours — render the rows on the server. This works on what is there; a table that appears only after a script has run is an empty box on first paint.
