Data table

Sorting, searching, paging and row selection over a table the server already rendered. It works on the rows that are in the document: it does not fetch, and it does not own the data.

When to use it

For a table a reader will interrogate — hundreds of rows, a search box, a sort. Not for thousands: there is no virtualisation, no in-cell editing and no export here, and a grid is a different product. Not for a handful of rows either, where a search box over six lines is furniture.

Accessibility

  • Built in — every sortable header is a real button inside the cell, so sorting is reachable without a pointer.
  • Built in — the sort state, the row count and the current page are announced in words, not only drawn.
  • Built in — numbers and dates are read in the page’s locale, so a sort agrees with what the reader sees.
  • Yours — give every row a stable key if you care which rows are selected after a sort.
  • Yours — name the search box and every row checkbox; “select row” is not a name when there are forty of them.
  • Yours — render the rows on the server. This works on what is there; a table that appears only after a script has run is an empty box on first paint.

Variants and states

NameWhat it is
.kp-datatable__barA row of controls above or below the table: the search box, the status line, the pager.
.kp-datatable__sortThe sort control inside a header cell. It takes the whole cell, so a click anywhere in the header sorts.
sorted ascending / descendingAn arrow after the header text and the sort state on the header itself; the arrow is the second carrier, the state is what is announced.
.kp-datatable__pager / __pageThe page controls and the “page m of n” label, in same-width digits.
.kp-datatable__page-sizeThe rows-per-page control, before the pager.
.kp-datatable__statusThe live region that says how many rows are showing after a search, a sort or a page.
.kp-datatable__searchThe search box. Typing is debounced so a long list is not re-sorted on every keystroke.
emptyWhen a filter matches nothing the empty state takes the table’s place rather than leaving a header over nothing.
clickable rowsA row can be marked as a control, which gives it the pointer cursor and an activation of its own.
