Key-value grid

A read-only list of facts: `dl.kp-kv` with `div.kp-kv__row` rows of a `dt` and a `dd`. The label column is as wide as the longest label and every value starts on one edge.

When to use it

The facts about one thing: a host, a release, a message. For editable settings use the form rows.

Framework-free markup

Server-rendered markup with the behaviour attached by js/auto.js, the one module that does anything on import. The snippets above are that markup, printed from the same string the example renders.

These are the framework-free channel's props. A selector is how a module finds an element, a read is a value you set on it, and a written one is state the module puts back for the stylesheet and for you to read.

NameWhat it is
.kp-kv--lines / --stack / --columnsA hairline between rows; each label over its value; lists side by side where there is room.
data-kp-changed / data-kp-state="error"A dot after the label; a red rule on the row’s start edge.
