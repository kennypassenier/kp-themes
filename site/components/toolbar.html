List toolbar

The bar above a list, a log, a board or a chart that is not (or not only) a data table: a search box, groups of filters (segmented controls or chips), a slot for a count or a switch, and a row of the filters that are on as removable tags. The zones sit on one grid row, so the search box keeps its width whatever the filter groups hold. js/toolbar.js clears the search on Escape, focuses it on a key, and draws the active row.

When to use it

Above any list the reader narrows down by typing and by a few filters. For a data table use its own header filters instead: the toolbar is the same idea for everything else.

Accessibility

  • Built in — the toolbar is a named group; Escape in the search clears it and fires `input`, so the page filters again.
  • Built in — removing a tag moves the focus to the next one, and Clear all returns it to the search.
  • Yours — name the toolbar, label the search, and call `setToolbarActive` again after a filter changes so the tags always say what is on.

Variants and states

NameWhat it is
.kp-toolbar__searchThe search zone: the field and, beside it, the key cap that focuses it.
.kp-toolbar__filtersThe filter zone: any number of `.kp-toolbar__group`, each a label over a segmented control.
.kp-toolbar__stateA slot for a count, a follow switch or a table/cards choice.
.kp-toolbar__activeThe filters that are on, as the data table’s removable tags and a Clear all button. Hidden when none is on.
