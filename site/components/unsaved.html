Unsaved changes bar

A bar that counts the rows you changed (“2 changes”), lists what was and what is, offers Save and Discard with Undo, and warns when you leave. It stands in the page header and, once the header is scrolled out of view, at the foot of the screen.

When to use it

A settings or edit page whose changes are written together. For a single field that saves itself, use the field’s own state.

Server-rendered markup with the behaviour attached by js/auto.js, the one module that does anything on import. The snippets above are that markup, printed from the same string the example renders.

Events

EventWhat it means
kp-unsaved-changeFired on the bar when the count changes: `{ count, changes }`.
kp-unsaved-saveFired on the bar, bubbling and cancelable, when Save is pressed: `{ changes }`.
kp-unsaved-discardFired on the bar when the changes were discarded: `{ changes }`; and `kp-unsaved-undo` when they were put back.
kp-unsaved-undoFired on the bar when a discard is undone: `{ changes }`.
kp-unsaved-leaveFired on the bar, bubbling and cancelable, when a link would leave a page with unsaved changes: `{ href }`.
kp-unsaved-revertFired on the bar, bubbling and cancelable, when one change is reverted: `{ key, row }`.

Accessibility

  • Built in — the count is announced politely, Save and Discard say why they are off, the list is a dialog with Esc, a refused save is an alert, Ctrl or Cmd+S saves.
  • Yours — answer `kp-unsaved-save` with `unsavedSaved`, and name the rows (`.kp-formrow__label`): the list uses them.

Variants and states

NameWhat it is
data-kp-placement`header+sticky` (default), `header` or `sticky-bottom`.
data-kp-dock`viewport` (default) or `container`, with `data-kp-scroll-root`.
data-kp-track`auto` (default) marks the rows as they are edited; `app` leaves it to the page.
data-kp-warn-leave`both` (default), `browser`, `app` or `off`.
data-kp-keep`session` (default) keeps the changes through a reload; `off`.
data-kp-undo-msHow long Undo is offered after Discard; 6000, 0 for none.
data-kp-save-labelThe Save words, `{n}` for the count.
configureUnsaved({ storage }) / attachUnsaved(root, { storage })Where the changes are kept: any object with `getItem`, `setItem` and `removeItem`, so a page that must not touch the browser’s session storage hands over its own.
data-kp-keep="local"`local` keeps the changes through closing the browser as well as a reload (`session`, the default, keeps them through a reload only).

Options written as attributes are read again when they change. A component of your own that reads options from attributes does the same with watchOptions(element, attributes, onChange) from js/live-options.js.
