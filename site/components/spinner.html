Spinner

A small ring that turns while something is happening whose end is not known. It stops turning for a reader who asked for less motion, and it says what it is in words.

When to use it

For a wait you cannot measure, and only for the part of the page that is waiting. Not for a whole page that is loading, where a skeleton shows the shape of what is coming; and not for something that finishes in a blink, where a spinner is a flash of anxiety.

Framework-free markup

Server-rendered markup with the behaviour attached by js/auto.js, the one module that does anything on import. The snippets above are that markup, printed from the same string the example renders.

These are the framework-free channel's props. A selector is how a module finds an element, a read is a value you set on it, and a written one is state the module puts back for the stylesheet and for you to read.

This unit reads no data attributes of its own.

Accessibility

  • Built in — the animation only runs where motion is welcome, which is DI7 and not a preference honoured where convenient.
  • Built in — the turn does not change luminance in a way that approaches the flash threshold, and the motion gate measures that.
  • Yours — give a standalone spinner a name, or nothing says what is being waited for.
  • Yours — say when the wait ends. A spinner that disappears is silent.

Variants and states

NameWhat it is
.kp-spinnerThe one size, set by a measure so a consumer can make it smaller inside a button.
reduced motionThe animation is inside the reduced-motion guard: for a reader who asked for stillness the ring is simply drawn, not turning.
decorativeBeside a label that already says what is happening, the ring is marked hidden so the wait is not announced twice.
