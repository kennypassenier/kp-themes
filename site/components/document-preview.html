Document preview

A PDF, a picture or a text shown in the viewer without downloading it, and the small page with a folded corner that means "a document". The browser's own PDF viewer shows a PDF; where it cannot, a plate offers Open in a new tab and Download.

When to use it

A dossier's files, a CV, an invoice: anything a person should be able to look at before deciding to keep it.

Live example

Framework-free markup

Server-rendered markup with the behaviour attached by js/auto.js, the one module that does anything on import. The snippets above are that markup, printed from the same string the example renders.

These are the framework-free channel's props. A selector is how a module finds an element, a read is a value you set on it, and a written one is state the module puts back for the stylesheet and for you to read.

Accessibility

  • Built in — the viewer is a native modal dialog; the icon is named ("PDF document"); keys o, d and p (and the arrows in a group) are listed in the shortcut sheet.
  • Yours — pass the file's real name as the title.

Variants and states

NameWhat it is
data-kp-previewThe file's address; empty: the opener is off with the reason "No file yet".
data-kp-preview-type`auto` (default: by extension, then Content-Type), `pdf`, `image` or `text`.
data-kp-preview-engine`native` (default) or `none`: no frame, only the plate with Open and Download.
data-kp-preview-size`wide` (default) or `full`.
data-kp-preview-actionsFoot buttons: `open download` by default, also `print` and `copy-link`.
data-kp-preview-titleThe dialog's title; the file's plain name by default.
data-kp-preview-pageOpen a PDF on this page (1).
data-kp-preview-sandbox`strict` (default for text: scripts removed) or `off`.
data-kp-preview-groupA name: openers that share it step previous and next in the same shell, with an exact "2 of 5".
data-kp-preview-nameThe file name a download is saved as.
data-kp-doc-kindOn the icon: `pdf`, `doc`, `sheet`, `image`, `text` or `unknown`.
data-kp-doc-linesOn the icon: 3 to 7 text lines (4; 7 for the large one).
data-kp-stateOn the icon: `missing` draws a faint, dashed empty page.
