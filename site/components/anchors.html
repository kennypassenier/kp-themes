Link anchors

A small # beside a heading or a row. A press copies a link to exactly that place and the mark says "Copied"; opening such a link scrolls to the place and marks it for two seconds. A link to something that is gone says so in a notice instead of doing nothing.

When to use it

Long pages and lists where one item must be pointed at in a chat: a guide with sections, a list of failed messages.

Server-rendered markup with the behaviour attached by js/auto.js, the one module that does anything on import. The snippets above are that markup, printed from the same string the example renders.

These are the framework-free channel's props. A selector is how a module finds an element, a read is a value you set on it, and a written one is state the module puts back for the stylesheet and for you to read.

Events

EventWhat it means
kp-anchor-copyFired on the mark when a link was copied: `{ id, url, text, markdown, ok }`.
kp-anchor-revealFired (cancelable) on the container before a link lands in a place that may be folded or on another page: `{ id, target }`.
kp-anchor-missingFired on the container when a hash has no place to land: `{ id }`.

Accessibility

  • Built in — the mark is a button with the target in its name, a tab stop after the row's own controls, always visible to keyboard focus; the copy is announced politely; with the shortcut engine `y` then `l` on a focused row copies its link.
  • Yours — give rows the id of the data, never their place in the list.

Variants and states

NameWhat it is
data-kp-anchors`headings`, `rows`, `both` or `off` (default): opt-in per page.
data-kp-anchorOn one element: its id, or empty to make one. An id the page already has is never overwritten.
data-kp-anchor-labelWhat the target is called in the mark's accessible name ("Copy link to Dead letter 4f2a").
data-kp-anchor-levelsWhich headings get a mark: `2,3` by default.
data-kp-anchor-show`hover` (default: over the heading or row, or the keyboard on it; always on a touch screen), `always` or `touch`.
data-kp-anchor-position`after` (headings) or `before` (rows).
data-kp-anchor-copy`url` (default) or `hash`.
data-kp-anchor-target`highlight` (default) or `none`: mark the place a link lands on.
data-kp-anchor-offsetA CSS length a sticky bar covers; the page header's own height by default.
data-kp-anchor-open`on` (default) opens a folded `details` first and asks the page to reveal a row on another page; `off`.
data-kp-flash-msHow long "Copied" stays on the mark (1500).
