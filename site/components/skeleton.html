Skeleton

Grey shapes standing in for content that is on its way, in the shape of what will arrive. It pulses where motion is welcome and stands still where it is not.

When to use it

For a first paint whose layout you already know — a list of cards, a table, a profile. Not for a short wait, where the skeleton is on screen more briefly than it takes to understand; and not where the shape is a guess, because a skeleton that does not match what arrives is a jump.

Framework-free markup

Server-rendered markup with the behaviour attached by js/auto.js, the one module that does anything on import. The snippets above are that markup, printed from the same string the example renders.

These are the framework-free channel's props. A selector is how a module finds an element, a read is a value you set on it, and a written one is state the module puts back for the stylesheet and for you to read.

Accessibility

  • Built in — the pulse changes opacity slowly enough to stay well under the flash threshold, and the motion gate measures it.
  • Built in — the animation stops entirely where less motion was asked for.
  • Yours — hide the skeleton from a screen reader. It stands for content; it is not content.
  • Yours — announce the arrival of the real thing, and keep the shape close enough that nothing jumps.

Variants and states

NameWhat it is
.kp-skeletonOne line, at the height of a line of text.
.kp-skeleton--blockA taller rectangle for an image, a card or a chart.
.kp-skeleton--circleA round one for an avatar; it keeps its aspect whatever width it is given.
stackedAdjacent skeletons take a distance from the stylesheet, so a paragraph of them needs no wrapper.
reduced motionThe pulse is inside the reduced-motion guard; the shapes are simply there for a reader who asked for stillness.
