Acknowledge gate

A warning that holds a button back until a box is ticked: “I read the release notes of 12.1”. The button says why it is off, and a press on it takes you to the first box still open.

When to use it

Before an action whose risk the reader must have understood: a major update, a restore over live data. It is a human guard, not a security control; the server checks again. Not for a plain “are you sure”: use a confirm.

Framework-free markup

Server-rendered markup with the behaviour attached by js/auto.js, the one module that does anything on import. The snippets above are that markup, printed from the same string the example renders.

These are the framework-free channel's props. A selector is how a module finds an element, a read is a value you set on it, and a written one is state the module puts back for the stylesheet and for you to read.

Accessibility

  • Built in — the guarded button keeps `aria-disabled` and its reason, so a press can answer by moving the focus to the first open tick; the change is announced once (“Update enabled”, “Update disabled: 1 release note still to read”); the whole label is the hit area, 44 px on a phone.
  • Yours — keep the server’s own check, and name the thing read in `data-kp-ack-label`.

Variants and states

NameWhat it is
the script`attachAckGates(root)` wires every `[data-kp-ack]` and returns a detach; `ackGate(el)` answers the handle of a gate. `ACK_GATE` is the selector; the events are `ACK_EVENT` (`kp-ack-change`, `{ key, checked, remaining, at }`) and `ACK_RETRY_EVENT` (`kp-ack-retry`).
data-kp-ack-for / -label / -link / -link-labelThe control(s) to enable (a selector, required), the tick’s words, the notes address and the words of its link (opened in a new tab; opening it ticks nothing for the reader).
data-kp-ack-tone / -min-ms / -focus / -key / -locked / -versionThe alert’s tone (`warning` default, `destructive` or `info`); a wait in milliseconds before the tick may be set; whether a press on the off control takes the focus to the first open tick (`off` to stop it); the name of the item in the event and the announcement; a lock while the job runs; and a version that clears the tick when it changes.
data-kp-checkedWritten on the gate while its box is ticked.
.kp-ack__frame / __side / __link / __tick / __labelThe parts: the frame round the alert and the tick, the side that holds the notes link, the link, the label with its checkbox and the sentence of the tick.
.kp-ack__wait / __bone / __problem / __problem-text / __retryThe loading state (skeleton lines, the height kept), and the failed one: no notes found, with Retry (`data-kp-ack-retry`, `kp-ack-retry`).
data-kp-ack-mode`each` (default): one tick per gate; `all`: one tick for the lot, for low-risk batches.
data-kp-ack-reset`on-change` (default): a changed key, label or version clears the tick; `never`.
data-kp-ack-require-linkThe tick stays off until the notes link was opened once; `data-kp-ack-min-ms` waits a time instead.
data-kp-state`loading` (skeleton lines, the height kept), `error` (no notes link found, with Retry on `data-kp-ack-retry`) or `empty` (no gate: hidden, the button simply on).
