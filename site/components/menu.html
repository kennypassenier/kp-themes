Dropdown menu

A list of actions on the popover layer, anchored under the control that opens it. The browser gives it light dismiss, Escape and focus return; the package gives it the looks and the anchor.

When to use it

For actions that belong to one thing and would crowd the row they sit in. Not for navigation, which reads better as links; not for a choice that changes a value, which is a select or a listbox; and not for more than a handful of entries, where a command palette or a page is kinder.

Accessibility

  • Built in — light dismiss, Escape and focus return are the browser’s, because a hand-written focus trap is how focus traps break.
  • Built in — the list scrolls inside the popover instead of running off the bottom of the window.
  • Yours — make every entry a real button or link; a div with a click handler is not reachable.
  • Yours — name the trigger, and say when it opens a menu rather than acting.
  • Yours — put a destructive entry behind the same confirmation you would give a destructive button.

Variants and states

NameWhat it is
.kp-popoverThe floating surface: its own ground, a boundary, a maximum height it scrolls inside, and a position taken from its anchor.
.kp-menuThe column of entries. It never wraps into a second column, whatever height it is given.
.kp-menu__itemOne entry: a real button that fills the row and wears no button chrome.
.kp-menu__item--destructiveAn entry in the destructive colour. It still needs a confirmation or an undo behind it.
.kp-menu__separatorA rule between groups of entries.
hoverA wash of the page’s ink rather than the accent colour, so a highlighted row is quiet in every theme.
