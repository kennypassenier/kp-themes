Weekday picker

The days a schedule runs on: seven chips (or the days of a month) with the quick picks Weekdays, Weekend and Every day and a line in words under them, “Mon and Thu”. Built on the chip group in multi mode; all seven days is a real choice.

When to use it

A schedule or a repeat that runs on chosen days. For one date use the date picker; for one of a few options use the segmented control.

Live example

Framework-free markup

Server-rendered markup with the behaviour attached by js/auto.js, the one module that does anything on import. The snippets above are that markup, printed from the same string the example renders.

These are the framework-free channel's props. A selector is how a module finds an element, a read is a value you set on it, and a written one is state the module puts back for the stylesheet and for you to read.

Accessibility

  • Built in — the chips are one tab stop with arrow keys; each is a toggle button with its full day name; the line in words is read when it changes.
  • Yours — name the picker (`aria-label`) after what it chooses, and keep your own copy of the days: the picker holds no data of yours.

Variants and states

NameWhat it is
weekdays / setWeekdays`weekdays(el)` gives the days that are on (numbers, 0 is Sunday); `setWeekdays(el, values)` sets them without an event; `weekdaysOf(el)` the days with their names.
weekdaySummary / monthSummary / dayNamesThe line in words for a set of days (“Mon and Thu”, “Every weekday”), the same for a month, and the names of the week in the reader’s language; `joinWords` joins a list the way the line does and `dayNumber` reads a name or a number.
data-kp-days`week` (default) or `month`: the days 1 to 31 and Last.
data-kp-week-starts-onThe first day, 0 (Sunday) to 6; the locale’s by default.
data-kp-day-names`short` (Mon) or `narrow` (M).
data-kp-minThe fewest days that make a schedule; 1 by default, 0 allows none.
data-kp-presetsThe quick picks, `weekdays,weekend,every`, or `false` for none.
data-kp-valueThe days at first, `1,4` or `mon,thu`.
data-kp-disabledThe whole picker is off; `data-kp-disabled-reason` says why, under the chips.
