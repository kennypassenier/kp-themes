Gallery

A grid of pictures that open large. The lightbox steps with the arrows and the keys, zooms to full size, plays a clip, and stops at the last picture (looping is an option). A picture that fails to load becomes a state tile with Retry, never a broken icon.

When to use it

Photos of a trip, a product, a recipe. For two versions of one picture, the compare slider.

Live example

Framework-free markup

Server-rendered markup with the behaviour attached by js/auto.js, the one module that does anything on import. The snippets above are that markup, printed from the same string the example renders.

These are the framework-free channel's props. A selector is how a module finds an element, a read is a value you set on it, and a written one is state the module puts back for the stylesheet and for you to read.

Accessibility

  • Built in — every tile is a button named after its picture; the lightbox is a native modal dialog with an exact, announced position; keys are listed in the shortcut sheet and need no AltGr.
  • Yours — give every picture an `alt` that says what is in it.

Variants and states

NameWhat it is
setGallery / openGalleryItem`setGallery(el, spec)` draws the grid (`items`, `state`, `message`, `label`, `actions`, `add`, `skeleton`); `openGalleryItem(el, id)` opens a picture from the page and `openGalleryFromHash(el)` the one the address names. `setGalleryUploading(el, reason)` turns the Add tile off, with the reason.
actions`setGallery(el, { actions: (item) => [{ label, tone, run, confirm }] })` adds buttons to a picture’s foot; a `confirm` question is asked first in the package’s confirmation dialog.
kp-gallery events`kp-gallery-open` `{ id, item }`, `kp-gallery-close`, `kp-gallery-retry` (the failed list), `kp-gallery-add` `{ files }` and `kp-gallery-picture-failed` `{ id }`.
data-kp-grid-columns`auto` (default: tiles of at least 9rem, two columns on a phone) or 2 to 8.
data-kp-tile-shape`square` (default) or `ratio`: each picture keeps its own shape.
data-kp-caption`hover` (default; always on touch), `always` or `none`.
data-kp-lightbox-loop`off` (default: the end is the end) or `on`.
data-kp-lightbox-preloadOriginals fetched beside the open one: 0, 1 (default) or 2.
data-kp-lightbox-zoom`on` (default) or `off`.
data-kp-lightbox-chrome`fade` (default: after 3 s without movement, never when calm) or `always`.
data-kp-lightbox-info`caption` (default), `details` (adds size) or `off`.
data-kp-lightbox-actionsMore foot buttons: `open`, `download`, `copy-link`.
data-kp-lightbox-hash`on` (default): the address carries the open picture and the back button closes it first; `off`.
data-kp-hash-prefixThe word before the id in the address (`photo`).
data-kp-lazy`on` (default) or `off`: lazy pictures with a box reserved from their size.
data-kp-state`loading` (busy card over the grid), `empty`, `error` or `ready`.
data-kp-rememberA name: the last opened picture is kept, with "Continue where you were".
