JSON field

A text box that knows JSON. It checks the text while it is typed, says what is wrong and where (“Line 3, column 12: expected ‘,’”) with the line marked in a gutter of line numbers, formats and minifies on request, and holds the form back while the JSON is broken.

When to use it

A field that takes a message body, action arguments or a settings blob. For showing JSON read-only use the code block.

Framework-free markup

Server-rendered markup with the behaviour attached by js/auto.js, the one module that does anything on import. The snippets above are that markup, printed from the same string the example renders.

These are the framework-free channel's props. A selector is how a module finds an element, a read is a value you set on it, and a written one is state the module puts back for the stylesheet and for you to read.

React usage

This unit has no React component; it is CSS and markup only.

Props

No props: this unit is CSS and markup only.

Events

EventWhat it means
kp-json-stateFired on the textarea, bubbling, when its state changed: `{ state, line, column, message, keys }`, state `empty` | `valid` | `invalid` | `text`.
kp-json-validateFired on the textarea, bubbling, for a text that parses: `{ value, text, schema, refuse(why) }`. A handler that calls `refuse` makes the field invalid with that sentence.

Accessibility

  • Built in — the message sits in a status line tied to the field with `aria-describedby`; Tab indents, Shift+Tab takes one indent off, Esc then Tab leaves the field, so the keyboard is never trapped; Mod+Shift+F formats.
  • Yours — label the field, and decide per field whether text that is not JSON may be sent.

Variants and states

NameWhat it is
explainJson(text)The check on its own (js/json-field.js): answers `{ ok: true, value }` or `{ ok: false, why, line, column }` in one wording whatever the engine says, so a page can word the same fault in its own validation.
data-kp-json`strict` (default: text that is not JSON blocks the form) or `allow-text` (it may be sent, and the line says so). Decided per field.
data-kp-json-check`input` (default, debounced 300 ms) or `blur`.
data-kp-json-format`button` (default: Format and Minify beside the field), `on-blur` or `off`.
data-kp-json-indent`2` (default), `4` or `tab`.
data-kp-json-gutterOn by default; `false` takes the line numbers away.
data-kp-json-wrapLong lines wrap and the gutter follows; by default they scroll inside the field.
data-kp-json-schemaA URL or inline JSON handed to the page in `kp-json-validate`, whose handler may refuse a value that parses.
