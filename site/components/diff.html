Diff

Two versions of a text side by side in one column: a line number, a sign, and the line. The sign has a column of its own, so the difference survives printing, high contrast, and a reader who cannot tell green from red.

When to use it

For showing what changed in something textual — a configuration, a record, a theme’s tokens. Not for a review tool with comments and threads, which is an application rather than a component. Not for two long documents: this is a rendering, not a diff algorithm.

Framework-free markup

Server-rendered markup with the behaviour attached by js/auto.js, the one module that does anything on import. The snippets above are that markup, printed from the same string the example renders.

These are the framework-free channel's props. A selector is how a module finds an element, a read is a value you set on it, and a written one is state the module puts back for the stylesheet and for you to read.

This unit reads no data attributes of its own.

React usage

import { Diff } from '@kp-soft/themes';

Declared in components/patterns.jsx; the package re-exports every component from its root.

Accessibility

  • Built in — the sign is text in its own column, which is the carrier that survives without colour.
  • Built in — the lines keep their whitespace, so indentation is part of what is compared.
  • Yours — say what the two sides are above the block. “Added” and “removed” are relative to something.
  • Yours — keep the numbers if the reader may need to point at a line.
