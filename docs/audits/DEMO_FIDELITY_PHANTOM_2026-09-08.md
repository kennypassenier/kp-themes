## What I was unsure about

- **A1's classification (copy content) is the single biggest judgment call in this report.** I placed it in Class A because the actual words on the page are a different theme's narrative, not a KT5-style short-string swap — but a case exists that S46's "same structure and elements" standard (as Kenny read it at the C5 gate, `docs/REALIZATION_PLAN.md:547`) was always meant to exempt body copy. I did not find anything in `docs/SCOPE.md`, `docs/CORRECTIONS.md`, or the REALIZATION_PLAN entries that settles this explicitly for prose copy (as opposed to structural markers), so I recorded it as a live, undecided question rather than silently classing it B.
- **Whether this same gap (shared cyberpunk copy under every theme's registered CSS) also affects retro, terminal, brutalism and synthwave** — I did not check those, since the task scope was phantom only, but `examples/concept.html` is one file for all of them (`examples/concept.html:18-23`), so it is very likely systemic. Worth a separate look if Kenny wants it.
- **A5/A6's "recorded reason" columns** — I searched `docs/CORRECTIONS.md`, `docs/SCOPE.md`, `docs/ARCHITECTURE_DECISIONS.md`, and `docs/DESIGN_INVARIANTS.md` for an explicit rationale (pointer-target size, DI11 reflow, a specific finding-and-approval exchange) and found none tied to phantom by name. It is possible one exists in a document I did not read in full (e.g. `docs/MINI_ROUNDS.md`, which I did not open), or in a chat exchange not captured in the repo.
- **The exact WCAG contrast figures in the demo's header comment (section 4, lines 28-31)** were not independently recomputed against the shipped token HSL values beyond a few spot conversions (background/foreground/primary/red-deep, which matched closely, within rounding). I did not recompute all thirteen pairs.
- **B1's classification** (view-timeline vs IntersectionObserver) could arguably be Class A rather than B — the demo did show a complete, working alternative mechanism (not something it merely "could not show"), it just happens to be superseded by the shared effects module's architecture. I erred toward B because the instructions' own example ("the effects module's hooks") matches this case closely, but flag the alternate reading.
