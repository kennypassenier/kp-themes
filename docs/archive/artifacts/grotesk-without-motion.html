without motion

The first proposal snapped the label's letter-spacing from 0 to 0.12em. That widens the label, so it widens the button — which is what you rejected. Both replacements below leave the box geometrically frozen: same width, same height, same padding, hovered or not. Only colour moves.

rejected · what it did

The letter clicked into the grid

Hover it. The button grows about 14 pixels wider, and anything beside it shifts.

↑ hover and watch the right edge

Measured: letter-spacing 0 → 0.12em over an 8-character label ≈ +13.8px of label width.

A · recommended

The ground arrives

A block of the theme's one red slides in from the leading edge, inside the button's own box, and the label reverses out of it as the edge passes — the letters are not recoloured, they are inverted by the block itself. Flat colour, one hard edge, reversed type: the Swiss poster move, and the only thing grotesk is allowed to be loud with is that red.

↑ the box does not move · hold it down for the deeper red

Box on hover: unchanged — the block is an absolutely positioned child scaling inside overflow: hidden. It carries the press too, so fix-12 is answered here rather than added later.

B · the quieter one

The grid shows

Touching the control briefly reveals the grid it sits on — an 8px rule set at 14% behind the label — and a red bar draws itself along the bottom edge. It says the same thing as A about grid and rigour, at about a quarter of the volume.

↑ the rules are the theme's own 8px step

Box on hover: unchanged — both layers are pseudo-elements at inset: 0 and the bar is inside the boundary.
