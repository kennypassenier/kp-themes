Am I through?

One page that answers the only question a round really has: is there anything left to judge. It counts every block of every component page against every theme, in this browser and this engine, and says how many carry a verdict — the register in the repository and the verdicts this browser holds, together.

It counts verdicts, not readings: a block that changed after it was judged shows on the review page itself, which reads every block again. So this page answers "did I go through everything", and the review page answers "does it still look the way I approved it".
