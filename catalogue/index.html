Every component, one page

Every block of every component page, gathered here so the whole package is reviewed in one place and every note ends up in one prompt at the foot of the page. The component pages stay where each block is written; this page reads them, so the two cannot drift.

Approving. Each block can be approved in the theme on screen. The page remembers what the block looked like at that moment — its markup and the computed style of every element in it — as a hash, in this browser. When anything that block paints changes, it shows as changed again. Tick Only blocks that need approval to see just those; untick it to see everything. Approvals are per theme, like the notes.

Comparing. Compare two themes puts one component under two themes side by side, element by element.
