# Retro's alarm headline: four faces

**Decided (scope-108): Instrument Sans, retro's own body face.**

Kenny rejected both retro alarms (2026-09-16): "het lettertype van 'Access denied' is te grof om deftig te lezen, kan je iets vinden dat nog altijd de oude vibe geeft van een oude windows, zonder zo extreem te zijn?"

[`demo.html`](demo.html) shows the real alarm four times at the size it draws: Pixelify Sans as it shipped, VT323 (the DOS voice retro already speaks, 0 new bytes), Instrument Sans (retro's own body face, 0 new bytes) and Archivo (+92.7 kB on a retro page). All four are OFL-1.1 and none reserves its name. Kenny picked Instrument Sans: the bevelled window, the title bar and the hazard stripes carry the era, so the headline does not have to.
