A VS Code colour theme, generated from kp-themes

Three VS Code windows below are mocks: HTML drawn to look like the editor, painted only with the colours in the generated theme file. The file is the one the extension in research/vscode/extension/ ships. Nothing on this page types a VS Code colour: the script reads the JSON and hands each key to the mock as a custom property.

What is what: the vsc- windows are mock; the page around them (headings, alerts, buttons, tables, the code block in section 4, the components in section 5) is package classes as they ship. The highlighting in the mock is a small tokenizer written for this page, not VS Code's TextMate engine, and it uses the innermost scope only.

                                The register against the theme file
                            
                            
                                

                                    The register does
                                    In VS Code
                                

                            
                            
                                

                                    
                                        Notched corners and clip paths on buttons, badges, dialogs, toasts (clip-path on 42 lines of the
                                        register, counted)
                                    
                                    
                                        No. VS Code 1.137 draws its own radii (buttons 4px, the quick pick 12px, from its
                                        cornerRadius.* sizes); no colour-theme property sets them.
                                    
                                

                                

                                    
                                        Glow: text-shadow and box-shadow halos (.glow-primary,
                                        .glow-card)
                                    
                                    
                                        No. Only widget.shadow and scrollbar.shadow take a colour; there is no text shadow.
                                    
                                

                                

                                    Fonts: Rajdhani body, Big Shoulders Display headings, KP Tech Mono for code and labels
                                    
                                        Not from a theme. The user sets editor.fontFamily and
                                        terminal.integrated.fontFamily; the workbench UI font is not a setting at all. VS Code reads
                                        system fonts only, and the package ships the mono as woff2, so it would have to be installed first.
                                    
                                

                                

                                    Uppercase, letter-spaced mono tabs and labels; the “— ” menu prefix
                                    No. Text transform and content are not themable.
                                

                                

                                    Motion: decipher, slice burst, the data-stream divider; scanline texture
                                    No. A colour theme has no motion and no images.
                                

                                

                                    Colour: yellow acts, red alarms, cyan labels, violet glitches; smoke on the void
                                    Yes, all of it, and the hero surface as the status bar.
                                

                            
                        

                    

                

                

                    

                        Look at: the left card is real package markup, so on cyberpunk its button is notched, its tabs are mono
                        capitals and the last line glows. The right side is the most VS Code will do with the same colours: flat plates, sentence-case
                        tabs, no halo. Switch to dark or light to see their registers on the left too; the other nineteen themes
                        have no register linked on this page.
                    

                    

                        How close it gets: every colour decision survives, none of the shape, type or motion does. The theme reads as cyberpunk from
                        across the room and as an ordinary editor up close.

                        the ground), the selection against the ground, and the current-line plate against the ground. The last two are non-text, and
