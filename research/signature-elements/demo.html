Signature elements

Ten elements that could carry a theme's identity the way the signature progress bar does. Each section shows the package's current look on the left and a drafted signature on the right. The markup in both columns is identical: the signature is CSS on the same classes, scoped to [data-theme], so the element's API and ARIA do not change per theme. Signatures are drafted for formal, cyberpunk and retro, plus one fourth theme per element; every other theme shows the package look in both columns. Motion uses only transform, opacity and clip-path, and stops under reduced motion. The strip under a signature is the same animation frozen at four moments.

Designed so far: formal, cyberpunk, retro. Themes marked “not designed yet” show the package look in both columns.
