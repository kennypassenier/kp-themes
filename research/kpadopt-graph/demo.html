The dashboard's Map, drawn by kp-graph

Kenny's rule: the look of the admin dashboard's Map never changes. Until now the dashboard drew it itself because kp-graph lacked three things on the Map. The section below puts the dashboard today (left) next to kp-graph with the new options (right), with the same made-up fleet in both, so you can confirm there is no visible difference in any theme.

Real: kp-graph (js/graph.js, css/components.css) and, in the left columns, the dashboard's own drawing code and CSS, copied word for word, only reformatted by prettier (dash-map.js, dash-map.css). Mock: the fleet, the adapters that hand the fleet to kp-graph, and the try-buttons. The new options are three attributes on the figure: data-kp-graph-colour="fixed", data-kp-graph-labels="under" and data-kp-graph-chrome="inside". The Map's column also carries the knobs --kp-graph-dot-cap: butt and --kp-graph-edge-on-width: 2.4 (see demo.css).

The Map: dashboard today against kp-graph
