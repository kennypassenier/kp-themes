Grotesk: which hover for a coloured button?

Measured on 2026-09-13: in grotesk a --primary, --destructive or bare --mirror button changes nothing on hover. The approved grotesk demo inverted a coloured button (fill becomes the page ground, the label takes the colour), but only when it also carried --mirror. The four columns below are the same six buttons under four rules. Hover each, then hold the mouse down: the press must still differ from the hover in every option. This page stays in grotesk; the theme menu is there if you want to see the others unchanged.

Four options, side by side

Look at: hover each button in each column, and Tab through them — focus shows the same change as hover. A is the package today. B gives every coloured button the demo's invert. C gives every variant the grey wash of the default button. D deepens the red to the theme's own hover value (--primary-hover hsl(0 100% 40%), --destructive-hover hsl(0 100% 35%)). Decide by which one still reads as grotesk: one red, black, white, and identity by letter rather than by effect.

A · today

Coloured buttons and a bare mirror do nothing on hover.

B · the demo's invert

A coloured button turns white with a red label; a bare mirror takes the grey wash.

C · grey wash everywhere

Every variant goes grey with a black label and edge while hovered.

D · a deeper red

A coloured button keeps its fill, one step darker; a bare mirror takes the grey wash.
