The JSON box

The JSON box that checks what you type

A text field that checks JSON, points at the error line and can format. By default text that is not JSON blocks the form (data-kp-json="strict"); a field that may also carry plain text says so itself (="allow-text"), decided per field.

Expected: changed since round 2: a long text scrolls again. In round 2 the box stayed six lines high with its scrolling switched off as soon as it sat inside the review dialog, so Long could not be scrolled at all. Now the box grows to 20 lines and then scrolls inside itself with the mouse wheel, the keyboard and its scrollbar, and the wheel also works over the line numbers. The numbers move with the text and the gutter stays exactly as tall as the box.

  • Press Long (an object with 8 entries, 42 lines): the wide box and the 390 px box both take it. Scroll to the last line with the wheel, with Ctrl+End or Page Down, and with the scrollbar: line 42 stands beside the last line. The 390 px box is narrow, so it has no line numbers there. Press Broken (line 3): line 3 is marked in the gutter. Everything else is as in round 2.

The box is the package's field in the mono face; the gutter a muted column with tabular numbers; the error line in the destructive ink and bold, with the field's edge turned red ink (the accountant's entry), never a tinted plate. Valid is quiet grey: nothing celebrates.
