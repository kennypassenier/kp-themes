Forest’s skeleton: five pictures

Kenny, 2026-10-07: the skeleton drawn as wide light diagonal stripes in a rounded bar “does not give forest vibes”; the planted tree line above it, he likes. This page is the alternative for the part that is not a tree line. Every option below draws the same scene with the package’s own skeleton parts in forest: a block, a circle, three text lines, a chart that is loading and a row of three loading cells in a datatable. Within one option all five shapes carry one picture, the way the register does it today.

Where the skeleton is used: the block is a chart’s loading state and its legend stubs (js/chart.js, the state box and kp-chart__source-stub) and an image or card placeholder; the circle is an avatar; the lines are paragraph text and every loading cell of a datatable (js/datatable.js).

Four options are new, the fifth is exactly what the package draws today (a plot being planted). The first is the recommendation. Each loops in 3200 ms like the rest of forest’s loading: it arrives, stands for a moment and leaves as the arrival played backwards.

Your system asks for reduced motion, so every option shows its finished still picture. Turn it off in the system settings to see the motion.
