Which element is nostromo's anchor?

Nostromo is the 1979 ship console: a moulded beige case with vent slots, label tape, screws and an indicator lamp on every switch, and set into it amber screens with scanlines, everything moving on an 80 ms frame clock (whole held frames, never a glide or a spring). Each candidate is one thing a console does; the question is which of them every other decision should come from. The network graph (the CRT radar) is in no scene and changes in no theme.
