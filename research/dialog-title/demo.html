The dialog title: the theme's own, or the fixed size

Kenny, 2026-10-03: "toon het verschil op een demopagina". Nine themes give their dialog title its own size, line height or block padding in the approved dialog designs, which scope-87 (heading metrics are the package's) refuses. Each theme below shows the same dialog twice, standing still and at the same scale: left as approved, right with the title at the package's size, line height and block padding. Kenny chose the right one for all nine; approving a theme takes the right one. Everything else (face, colour, case, ornaments) is the same in both.
