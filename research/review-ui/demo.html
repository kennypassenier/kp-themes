A faster way to judge: three prototypes

Today's dialog (research/_review/) walks one theme × aspect per page, with the demo's own state buttons mirrored above that you click to see each option's motion. These three try to get the motion playing by itself and cut the clicking. Nothing here touches the real dialog or the character demos; every pick is written to the same storage key they use, so it stays a real answer.

1 · Autoplay cards

One aspect per screen, every option as a big card already looping its own motion.

  1. Click a card, or press 1–6, to pick
  2. N for "None of these" + a note
  3. Next screen comes by itself
  4. ← previous · P pause · S speed
Open

2 · Flip compare

One huge stage, one option at a time; flip instantly, motion restarts every flip (an eye test).

  1. ←/→ flips between options
  2. Space/Enter picks the shown one
  3. N for "None of these" + a note
  4. Backspace previous · P pause · S speed
Open

3 · Contact sheet

One aspect across every open theme at once, a row per theme, options small and autoplaying — good for consistency.

  1. ↑/↓ moves the active theme row
  2. 1–6 picks in the active row
  3. N for "None of these" + a note
  4. Backspace previous aspect · P pause · S speed
Open
