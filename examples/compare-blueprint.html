What is different

  • Typography: Instrument Sans now ships with the package and loads here; 4.0.0 shipped no font file, so the browser drew the system fallback.
  • Typography, still the fallback: ui-monospace carries a Reserved Font Name and waits on R6-Q1 — no visible change yet.
  • New in 5.0.0: 11 hero tokens and the display text step, all pointing at values this theme already had — the hero paints the same ground as the app, so nothing visible changed.
