What is different

  • Typography: Archivo now ships with the package and loads here; 4.0.0 shipped no font file, so the browser drew the system fallback.
  • Typography, still the fallback: KP Ticker Mono carries a Reserved Font Name and waits on R6-Q1 — no visible change yet.
